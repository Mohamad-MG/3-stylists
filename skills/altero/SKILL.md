# Altero

Resolve references relative to this loaded skill. Keep the project and the plugin
installation separate. Reply in the user's language.

| Mode | Use it for | Deliverable |
| --- | --- | --- |
| audit | Read-only review of a site, source, or screenshots | Prioritized findings with evidence and coverage |
| polish | Small refinements within an existing design | Focused fixes with before/after evidence |
| enhance | Improvement of a named flow or existing surface | Scoped changes with interaction checks |
| build | A new frontend from a brief | Working first slice |
| explore | Explicit request for three independent variants | Follow [Explore](references/explore.md) |

Honor the requested mode and no-edit instructions. Treat plans and reviews as audit.
Choose polish for localized refinements, enhance for flow-level changes, and build
for a new-project brief. If there is no target, show the modes and ask for one.
Read the [shared workflow](references/workflow.md) for all four standard modes.
Read Explore only when requested.

Standard modes use the host's available tools and the project's stack. They
require no third-party design engines. With limited repo or browser access, use
available files and screenshots and provide findings or a proposed patch as
appropriate. Label unverified behavior and never claim inaccessible files were edited.
